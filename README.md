## 🎮 The SPSU Logo Algorithmic Lore
The SPSU Logo symbolizes the pinnacle of computational architecture:
- **Upper Royal Blue Circuit Canopy (Recursion & Networks)**: Represents Trees, Binary Search Trees, AVL Rotations, Graph Traversals (BFS/Dijkstra), and Recursive Backtracking.
- **Central Horizon Divider Line**: Represents Logarithmic Bisecting (Binary Search) and Pivot Partitioning (QuickSort / MergeSort).
- **Lower Cyan/Teal Frequency Pillars (Linear & Tabular Structures)**: Represents Contiguous Arrays, Memory Buffers, LIFO Stacks, FIFO Queues, and Dynamic Programming Memoization Tables.

In **SPSU DSA Odyssey**, the central Cyber-Core has fractured! The player registers as an SPSU Cadet, conquers 10 interactive levels, and progressively energizes the SPSU Logo Matrix until reaching 100% full-charge harmony to defeat the Glitch King and claim their **Verified SPSU Certificate of Algorithmic Mastery**.

## 🚀 How to Play & Run Offline

### Method 1: Instant Standalone (Zero-Install, 100% Offline)
Simply double-click:
`C:\Users\LC\.gemini\antigravity\scratch\spsu-dsa-quest\spsu_dsa_quest_standalone.html`
It runs in **any browser** on Windows, Mac, Linux, or Mobile without requiring Node.js, internet, or a web server!

### Method 2: Local Game Server (PWA Enabled)
```bash
cd "C:\Users\LC\.gemini\antigravity\scratch\spsu-dsa-quest"
node server.js
```
Open [http://localhost:3888](http://localhost:3888) in your browser. You can click the browser's install button to add it as a native Desktop / Mobile Progressive Web App!

### Method 3: In-Game Download
Inside the game, simply click the **"💾 Download App"** button in the top navigation bar to save the complete standalone portable `.html` directly to your downloads folder.
